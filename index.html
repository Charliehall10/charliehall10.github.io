Specimen Hunter

Browser game with its own game server · 2026

An original British carp-fishing slot game (5 reels, 10 lines) with free spins, baited swims and a kingfisher bonus. It has its own game server with sessions, stake limits and round history, and also ships as a Linux desktop app.

How I checked itAutomated tests cover the game engine and the server API. A Python simulator played 500 million rounds to confirm the game pays out as designed (96.16% return to player), and the JavaScript engine is checked against it.

Daily Check VR

HGV driver training · Unity 6 · desktop, browser and VR · 2026

A trainer for the daily walkaround check every lorry driver must do. Walk round an articulated lorry, inspect all 21 DVSA checks, judge each defect as minor or dangerous, then file a defect report and get scored. Training mode teaches; Assessment mode plants random defects with no hints.

How I checked itA built-in test mode plants every defect at once and screenshots every check close-up, the report and the results, so I can review the whole lorry after every change.
  • Unity 6
  • C#
  • OpenXR
  • WebGL

Extinction Dash

One-button runner · Unity 6 · 2026

A pixel-art dinosaur runner across five levels, each faster than the last, ending under a giant meteor. Amber combos raise your multiplier and trigger a Stampede. All art and sound are generated in code, and the levels are built so spacing stays fair as the speed climbs.

How I checked itA test bot plays through all five levels to confirm each one can be completed.

Tick Lab

Browser trainer · TypeScript · 2026

A trainer for “tick manipulation”, a set of precise click rhythms in Old School RuneScape. It recreates the game's 600 ms server tick and network delay, and a coach explains exactly which tick each click landed on and why a roll was lost.

How I checked it32 automated tests replay a community guide's tick-by-tick examples, and a bot follows each lesson for 300 ticks to confirm the perfect rhythm comes out.
  • TypeScript
  • Vite
  • Canvas 2D
  • Vitest

Space Adventure

2D platformer · Unity · first-year university project (2019), remastered 2026

My first-year game at Bath Spa, rebuilt as a complete short game: five levels, one rocket part each, ending in a three-phase boss fight. It keeps the original 2019 art and adds wall jumps, moving platforms, checkpoints, a results screen and chiptune music.

How I checked itThe levels are written in a Python level-design tool that simulates the player's jump physics, to prove every level can be finished and every star reached. A self-test mode checks the real game matches.
  • Unity

  • Python
  • Level design

About me

Background

I studied Creative Computing at Bath Spa University, a BSc on the Gaming pathway followed by an MSc, where I designed and built games in Unity and C#. The MSc included a Creative Leadership module on planning and leading creative projects.

Since graduating I have kept building projects in my own time, with a focus on testing: automated tests, bots that play through each level, and simulations to check a game behaves as designed.

Alongside that I've spent years in customer-facing and team roles. At Carphone Warehouse I diagnosed customers' device and account problems; at Waitrose and British Wool I trained new colleagues. These roles gave me good communication skills and a methodical approach to solving problems.
